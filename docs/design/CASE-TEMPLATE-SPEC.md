## 2. 模版的固定结构

三份模版的字段分组**高度一致**，说明这是患者社群的通行格式：

```text
病情介绍
├─ 姓名 · 年龄 · 性别 · 电话
├─ 身高 · 体重
├─ 病历/就诊号
└─ 病名
基因检测
病理免疫组化
既往治疗史
```

对照工作台的实体模型：

| 模版区块 | 工作台实体 | 覆盖状态 |
|---|---|---|
| 基本情况 | `Patient` | ✅ 已有 |
| 病名 | `ClinicalFact`（诊断/分期） | ✅ 已有 |
| 基因检测 | `GenomicAlteration`（assayType=NGS） | ✅ 已有 |
| 病理免疫组化 | `GenomicAlteration`（assayType=IHC）+ `ClinicalFact`（病理描述） | ✅ 已有 |
| 既往治疗史 | `TreatmentLine` + `TimelineAnnotation` + `Observation` | ✅ 已有 |

**结论：v0.4 的实体模型无需新增实体，只需明确字段级映射。** 这是好消息——数据模型设计经受住了真实模版的检验。

## 3. 字段级映射

### 3.1 基本情况

真实模版示例（李菊）：

```text
姓名 李菊五  年龄 58  性别 女  电话
身高 152CM  体重 57 kg  病历/就诊号
病名 胰体癌 PT2N0M0，中分化腺癌，胰体尾+脾脏切除
```

| 模版字段 | 工作台字段 | 处理规则 |
|---|---|---|
| 姓名 | `Patient.nickname` | **不强制真实姓名**；模版有真名但工作台按隐私优先，允许昵称 |
| 年龄 | `Patient.age` 或由出生年推算 | 模版记静态年龄，会过期。推荐记出生年，显示时算年龄 |
| 性别 | `Patient.sex` | 直接映射 |
| 电话 | **不采集** | 工作台无需联系方式；如需记录，放患者档案的可选备注，不做结构化字段 |
| 身高 / 体重 | `Observation`（身高、体重） | 模版里是单一值，工作台应记为**带日期的记录**并可累积 |
| 病历/就诊号 | `ClinicalFact`（可选） | 医院内部号，跨院不通用，标为可选 |
| 病名 | `ClinicalFact.diagnosis` + `stage` + `surgery` | 需拆分为三个字段：诊断、分期、手术方式 |

**关键改进点**：「病名」在模版里是一句话（`胰体癌 PT2N0M0，中分化腺癌，胰体尾+脾脏切除`），混了四个信息。工作台必须拆分，否则无法用于匹配规则。

拆分规则：

| 子字段 | 示例值 | 用途 |
|---|---|---|
| 诊断 | 胰体癌 | 匹配 `disease_type` |
| 分期 | pT2N0M0 | 匹配 `stage` |
| 分化 | 中分化 | 匹配 `histology` |
| 手术 | 胰体尾+脾脏切除 | 治疗史 |

### 3.2 基因检测

真实模版示例（赵军营）：

```text
2025-06-02基因检测：
ARID1A p.S1085 1.29%；KRAS p.G12V, 24.86%；TP53 p.E349 27.16%突变；
微卫星稳定 MSS
```

李菊：

```text
KRAS G12V，TP53 R248W，丰都均＜4%，肿瘤突变负荷 0.86 个突变/Mb，
微卫星稳定，肿瘤细胞比例 10%
```

| 模版字段 | 工作台字段 | 处理规则 |
|---|---|---|
| 检测日期 | `GenomicAlteration.reportDate` | 直接映射 |
| 基因名 + 变异 | `GenomicAlteration.gene` + `.variant` | 拆开：`KRAS` + `p.G12V` |
| 丰度/频率 | `.vaf`（新增子字段） | `24.86%`、`＜4%` —— **注意「＜4%」是阈值不是精确值**，须保留比较符 |
| MSI 状态 | `assayType='MSI'` 的记录 | `MSS` / `MSI-H` / `dMMR` |
| TMB | `.tmb`（新增子字段） | `0.86 个突变/Mb`，含单位 |
| 肿瘤细胞比例 | `.tumorCellPct`（新增子字段） | `10%`，影响变异解读，需保留 |

**必须注意**：`「丰都均＜4%」` 显然是「丰度均＜4%」的笔误（赵军营模版里也有类似错字如 `ARIDIA` 应为 `ARID1A`）。抽取器必须：

- 保留**原文**，不擅自纠正用户看到的文本
- 归一字段用**标准名**，并记录「自动归一」标记
- 允许用户手动纠正，纠正后保留原始文本

### 3.3 病理免疫组化

真实模版示例（赵军营）：

```text
2025-05-16术后病理：
组织学类型:腺鳞癌(约60%中-低分化导管腺癌+40%中分化鳞状细胞癌)
肿瘤大小/范围:3.0cm×2.8cm×2.0cm
浸润深度和范围:浸润胰腺实质，浸润胰腺周围纤维脂肪组织，累及胆总管
脉管内癌栓:有   神经侵犯:有
切缘:R0切缘 d>1mm未侵犯
免疫组化:(特检编号:A2025-13805)
  HER2(0), MLH1(蛋白表达), MSH2(蛋白表达), MSH6(蛋白表达), PMS2(蛋白表达),
  Ki67(平均约60%+), O-met(约80%+, 弱-中等), Claudin18.2(约20%+, 弱-中等),
  S100p(部分+), MUC5ac(部分+), CK7(+), MUC-1(+), P40(部分+), P63(部分+),
  PD-L1(22C3)(CPS<1)
```

这是**信息密度最高的区块**，也是最需要结构化的。

| 模版字段 | 工作台字段 | 说明 |
|---|---|---|
| 报告日期 | `reportDate` | 直接映射 |
| 组织学类型 | `ClinicalFact.histology` | 长文本，保留原文 |
| 肿瘤大小 | `ClinicalFact.tumorSize` | `3.0×2.8×2.0cm`，保留三围 |
| 浸润范围 | `ClinicalFact.invasion` | 长文本 |
| 脉管内癌栓 / 神经侵犯 | `ClinicalFact.vi` / `.pni` | 枚举：有/无/未知 |
| 切缘 | `ClinicalFact.margin` | `R0` / `R1` / `R2` + 描述 |
| IHC 各项 | `GenomicAlteration`（assayType=IHC），每项一条 | 见下表 |
| 特检编号 | `ClinicalFact.labNo` | 可选，回原件的辅助键 |

**IHC 结果的表达差异极大**，这是最容易出错的地方：

| 模版里的写法 | 含义 | 结构化处理 |
|---|---|---|
| `HER2(0)` | 评分 0 | `result='0'`, `resultType='score'` |
| `CK7(+)` | 阳性 | `result='阳性'`, `resultType='binary'` |
| `Ki67(平均约60%+)` | 60% 阳性 | `result='60%'`, `resultType='percent'`, 保留「平均约」为备注 |
| `Claudin18.2(约20%+, 弱-中等)` | 20%，强度弱到中等 | `result='20%'`, `intensity='弱-中等'`, `resultType='percent'` |
| `MLH1(蛋白表达)` | 表达保留（即阳性） | **这是隐性表达**，需专门映射为「表达保留」 |
| `PD-L1(22C3)(CPS<1)` | CPS 评分 <1 | `result='CPS<1'`, `resultType='cps'`, `assay='22C3'` |
| `O-met(约80%+, 弱-中等)` | 80%，弱到中等 | 同 Claudin18.2 |
| `S100p(部分+)` | 部分阳性 | `result='部分阳性'`, `resultType='partial'` |
| `P40(部分+)` | 部分阳性 | 同上 |

**结论：IHC 结果不能用单一字符串字段**。需要：

```yaml
assayType: IHC
marker: Claudin18.2
resultType: percent | binary | score | cps | partial | expression
result: "20%"
intensity: "弱-中等"        # 可选
assay: "22C3"               # 可选，PD-L1 专用
rawText: "Claudin18.2(约20%+, 弱-中等)"   # 原样保留
normalizedBy: auto | user
```

**「未检测」与「阴性」必须区分**（MATCHING-SPEC §3.3 已强调）。模版中 `PD-L1` 在赵军营有值、在李菊完全没有出现——**没出现 ≠ 阴性**，工作台必须显示「未检测」或「未记录」。

### 3.4 既往治疗史

真实模版示例（李菊，最有代表性）：

```text
2024-10-10：在重庆附二院体检，发现CA199 543。
2024-10-29：行 EST+内镜下奥狄氏括约肌扩张术+ERCP，置入胆管、胰管塑料支架
2024-12-17：腹腔镜下根治性顺行模块化胰体尾+脾脏切除术
2025-2-15：开始脂质体四药化疗六次三个月
2025-5-26：因CA199连续升高，切换为AG方案，共4个周期，12次化疗
2025-11-10：因连续化疗7个月，改用替吉奥维持三个月四个疗程
2026-01-26：重启AG化疗，当前完成两次
```

这个区块**混合了三种信息**，必须分流：

| 信息类型 | 示例 | 去向 |
|---|---|---|
| 日期锚点事件 | `2024-12-17 手术` | `TimelineAnnotation` + `TreatmentLine`（手术线） |
| 方案变更 | `2025-2-15 开始脂质体四药化疗` | `TreatmentLine` |
| 指标记录 | `发现CA199 543` | `Observation` |
| 操作/介入 | `ERCP 置入支架` | `TreatmentLine`（非药物治疗）+ `CatheterRecord` |
| 变更原因 | `因CA199连续升高` | `TreatmentLine.stopReason` |

**治疗线数的自动推导**：模版里用户写「四药 → AG → 替吉奥 → 重启AG」，工作台应能：

1. 识别每个方案的起止 → 生成 `TreatmentLine`
2. 按时间排序 → 推导线数序号
3. **但允许用户手动调整**——「重启 AG」算三线还是「回到二线方案」在医学上有争议，工作台不替用户决定

**这是必须暴露的歧义**：线数直接输入匹配规则，算错会导致匹配结论错误。

## 4. 抽取器设计

### 4.1 分阶段抽取

```text
PDF/图片 → 文本提取 → 区块识别 → 字段抽取 → 候选值 → 人工核对 → 确认入库
```

沿用 v0.3 §5.2 的链路，不新增机制。

### 4.2 区块识别规则

模版结构固定，可先用**规则法**识别区块，再对区块内容用 AI 抽取：

| 区块 | 识别锚点 |
|---|---|
| 基本情况 | `病情介绍` / `姓名` + `年龄` |
| 基因检测 | `基因检测` / `基因` |
| 病理免疫组化 | `病理` / `免疫组化` / `术后病理` |
| 既往治疗史 | `既往治疗史` / `治疗史` |

**规则法优先于纯 AI**：模版结构稳定时，规则法更可预测、更便宜、更好调试。AI 只用于区块内的自由文本抽取。

### 4.3 抽取结果必须带的三样东西

| 必带 | 为什么 |
|---|---|
| **原文片段** | 用户能对照核实；模版错字多（`ARIDIA`、`丰都`），原文是唯一真相 |
| **页码/位置** | 能跳回原件定位 |
| **置信状态** | 哪些是自动归一、哪些需人工判断 |

### 4.4 必须标记为「需人工确认」的情况

| 情况 | 为什么不能自动定 |
|---|---|
| 治疗线数序号 | 「重启方案」算几线有争议 |
| 隐性表达（`MLH1(蛋白表达)`） | 需要医学知识才能确定含义 |
| 带比较符的值（`<4%`、`CPS<1`） | 不是精确值，不能当数值参与计算 |
| 缺失字段 | 「没提到」≠「阴性」 |
| 化疗次数与周期数不一致 | 模版里 `4个周期，12次化疗` 需要交叉验证 |

## 5. 汇总模版的输出格式

工作台的「病情汇总」（UI-DESIGN §5）应能**导出接近模版格式**的文档，因为患者社群已经在用这个格式互相交流。

推荐的导出结构：

```text
病情介绍
姓名 ___ 年龄 ___ 性别 ___ 身高 ___ 体重 ___
病名 ___（诊断 + 分期 + 分化 + 手术）

基因检测
___（日期 + 逐个变异 + MSI + TMB）

病理免疫组化
___（日期 + 组织学 + IHC 逐项）

既往治疗史
___（按时间排序的事件 + 方案 + 指标变化）

附：资料清单与引用编号
```

**与模版的差异（必须说明）**：

| 差异 | 原因 |
|---|---|
| 电话不导出 | 隐私优先 |
| 治疗线数显式标注 | 模版没写线数，但匹配需要 |
| 每条记录附来源引用 | 模版没有，但工作台的可追溯原则要求 |
| 保留原文错字 + 归一字段 | 模版只有原文，工作台两者都留 |

## 6. 对 v0.4 数据模型的修订

基于真实模版，`GenomicAlteration` 需要补充子字段：

| 新增字段 | 用于 | 示例 |
|---|---|---|
| `vaf` + `vafOperator` | 变异丰度及比较符 | `24.86%` / `<4%` |
| `tmb` + `tmbUnit` | 肿瘤突变负荷 | `0.86 个突变/Mb` |
| `tumorCellPct` | 肿瘤细胞比例 | `10%` |
| `resultType` | IHC 结果类型 | `percent` / `binary` / `score` / `cps` / `partial` / `expression` |
| `intensity` | 染色强度 | `弱-中等` |
| `assay` | 检测平台/克隆号 | `22C3` |
| `rawText` | 原文片段 | 必填 |
| `normalizedBy` | 归一来源 | `auto` / `user` |

`ClinicalFact` 需要补充：

| 新增字段 | 用于 |
|---|---|
| `histology` | 组织学类型 |
| `tumorSize` | 肿瘤大小 |
| `invasion` | 浸润范围 |
| `vi` / `pni` | 脉管癌栓 / 神经侵犯 |
| `margin` | 切缘状态 |
| `labNo` | 特检编号（可选） |

新增实体 `TimelineAnnotation`（见 TIMELINE-SPEC §3.3）。
