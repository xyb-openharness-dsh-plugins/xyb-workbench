日期：2026-10-13 · 状态：**设计建议稿。参考范围取自通行临床区间，实施前需按实际检验机构复核。**

上级文档：[SPEC-v0.4.md](./SPEC-v0.4.md) · [TIMELINE-SPEC.md](./TIMELINE-SPEC.md)。

---

## 1. 为什么要建指标目录

现有 `ca199_toolbox/data.csv` 实测只有 14 个指标：

```
血红蛋白 51 · 血糖 51 · 胆固醇 51 · 肌酐 51 · 白蛋白 51
甘油三酯 51 · 总胆红素 51 · 尿酸 51 · C反应蛋白 51 · CA199 51
AST 51 · ALP 51 · ALT 50 · 体重 3
```

**三个问题**：

| 问题 | 说明 |
|---|---|
| **无肿瘤标志物组合** | 只有 CA199，缺 CEA / CA125 / CA724 / CA50 / AFP |
| **无血常规主要项** | 缺 WBC、RBC、PLT、中性粒细胞等 |
| **完全没有参考范围** | 实测工具源码中无参考范围字段，因此无法判断异常 |

**结论**：需要一个**指标目录**，定义：每项指标的规范名、单位、参考范围、所属类别、危险值、临床意义。它同时服务三处：趋势图分类、报告核对的范围校验、看板的异常判断。

## 2. 六大类指标

### 2.1 肿瘤标志物

| 指标 | 规范名 | 单位 | 参考范围 | 危险/警戒 | 说明 |
|---|---|---|---|---|---|
| CEA | 癌胚抗原 | ng/mL | 0–5 | — | 广谱标志物，胰腺癌可升高 |
| CA19-9 | 糖类抗原 19-9 | U/mL | 0–37 | — | 胰腺癌最常用；Lewis 抗原阴性者可不升高 |
| CA125 | 糖类抗原 125 | U/mL | 0–35 | — | 腹膜转移时可升高 |
| CA72-4 | 糖类抗原 72-4 | U/mL | 0–6.9 | — | 胃癌、胰腺癌相关 |
| CA50 | 糖类抗原 50 | U/mL | 0–25 | — | 与 CA19-9 常同步 |
| AFP | 甲胎蛋白 | ng/mL | 0–7 | — | 肝转移或肝细胞癌时参考 |

**注意**：肿瘤标志物的升降**不能自动解释为疗效或进展**（见 §5）。

### 2.2 血常规

| 指标 | 规范名 | 单位 | 参考范围 | 危险/警戒 | 说明 |
|---|---|---|---|---|---|
| WBC | 白细胞计数 | ×10⁹/L | 3.5–9.5 | **<2.0 或 >20** | 感染 / 骨髓抑制 |
| RBC | 红细胞计数 | ×10¹²/L | 3.8–5.1 | — | 贫血评估 |
| **HGB** | 血红蛋白 | g/L | 115–150 | **<100 警戒 / <70 危险** | **消化道出血重点**（见下） |
| PLT | 血小板计数 | ×10⁹/L | 125–350 | **<50 警戒 / <20 危险** | 出血风险；化疗抑制 |
| NEU% | 中性粒细胞百分比 | % | 40–75 | — | 细菌感染 / 炎症 |
| LYM% | 淋巴细胞百分比 | % | 20–50 | — | 免疫状态 |
| MONO% | 单核细胞百分比 | % | 3–10 | — | — |
| **NEU** | 中性粒细胞绝对值 | ×10⁹/L | 1.8–6.3 | **<0.5 危险** | 粒缺伴发热需急诊 |

#### HGB 与消化道出血（用户特别指出）

**HGB < 100 g/L 是重点警戒线**，对胰腺癌患者尤其重要：

| 区间 | 分级 | 意义 |
|---|---|---|
| ≥115 | 良好 | 正常 |
| 100–114 | 关注 | 轻度贫血 |
| **70–99** | **警示** | **中度贫血；胰腺癌患者需警惕消化道出血** |
| <70 | 警示（更高） | 重度贫血，通常需输血评估 |

**为什么消化道出血要单独提示**：胰腺癌可侵犯消化道或引起门脉高压相关出血，HGB 下降常常是首发信号。因此：

- HGB 跌入 70–99 时，看板「并发症」维度联动提示，并列出「消化道出血」作为可能原因之一（**只提示关联，不下诊断**）
- 若同时有「消化道出血」记录或黑便等主诉，标为更高优先级

**这是指标目录与并发症管理的联动点**，见 §4。

### 2.3 肝功能

| 指标 | 单位 | 参考范围 | 说明 |
|---|---|---|---|
| ALT | U/L | 7–40 | 肝细胞损伤 |
| AST | U/L | 13–35 | 肝细胞 / 肌肉 |
| ALP | U/L | 45–125 | **胆道梗阻敏感**；胰腺癌重要 |
| GGT | U/L | 7–45 | 胆道 |
| 总胆红素 | mg/dL | 0.3–1.2 | **胆道梗阻直接指标** |
| 直接胆红素 | mg/dL | 0–0.3 | 梗阻性黄疸鉴别 |
| 白蛋白 | g/L | 40–55 | 营养 + 肝合成功能 |

**ALP + 总胆红素 + 直接胆红素**是胰腺癌胆道梗阻的三联观察项。

### 2.4 肾功能（化疗评估）

| 指标 | 单位 | 参考范围 | 说明 |
|---|---|---|---|
| 肌酐 | μmol/L | 44–104（男）/ 44–97（女） | 化疗剂量调整依据 |
| 尿素 | mmol/L | 2.9–8.2 | — |
| eGFR | mL/min/1.73m² | ≥90 | 由肌酐推算；<60 需调整用药 |
| 尿酸 | μmol/L | 155–357（女）/ 208–428（男） | 肿瘤溶解 |

**为什么肾功能单列**：多数化疗药（尤其铂类、吉西他滨）需按肾功能调整剂量。这是**治疗安全性指标**，不只是"看看有没有病"。

### 2.5 感染类指标

| 指标 | 单位 | 参考范围 | 说明 |
|---|---|---|---|
| **CRP** | mg/L | 0–8 | 炎症/感染敏感 |
| **PCT** | ng/mL | <0.05 | **细菌感染特异性优于 CRP** |
| SAA | mg/L | 0–10 | 血清淀粉样蛋白 A |
| 白介素-6 | pg/mL | 0–7 | 炎症因子 |

**PCT 与 CRP 的分工**：

| | CRP | PCT |
|---|---|---|
| 升高时机 | 感染后 6–8 h | 感染后 2–4 h |
| 特异性 | 低（肿瘤、创伤均可升） | **较高（细菌感染）** |
| 用途 | 趋势观察 | 判断是否细菌感染 |

肿瘤患者 CRP 常因肿瘤本身升高，**因此 PCT 更有鉴别价值**。

### 2.6 代谢与营养

| 指标 | 单位 | 参考范围 | 说明 |
|---|---|---|---|
| 血糖 | mmol/L | 3.9–6.1 | 胰腺癌常伴糖代谢异常 |
| 糖化血红蛋白 | % | 4.0–6.0 | 长期血糖 |
| 甘油三酯 | mmol/L | <1.7 | 胰腺外分泌功能不全可致吸收不良 |
| 胆固醇 | mmol/L | <5.2 | 同上 |
| 体重 | kg | 个体化 | 与营养管理同源 |

**胰腺癌与血糖**：新发糖尿病可能是胰腺癌早期表现，因此血糖值得常规跟踪。

## 3. 数据模型

指标目录作为**随包资源**（不随患者数据变化）：

```yaml
- key: HGB
  name: 血红蛋白
  aliases: [Hb, 血红蛋白, HGB, 血色素]
  category: cbc            # tumor_marker | cbc | liver | kidney | infection | metabolic
  unit: g/L
  refLow: 115
  refHigh: 150
  warnLow: 100             # 警戒线
  dangerLow: 70            # 危险线
  direction: up_good       # 用于箭头着色（见 CARE-MANAGEMENT-SPEC §2.5.1）
  note: 消化道出血重点观察项
```

`Observation` 通过 `key` 关联目录；**指标别名归一**（`CA199` / `CA19-9` / `糖类抗原19-9` → 同一 `key`）。

## 4. 三处联动

### 4.1 指标趋势页

按类别分组展示，**支持多指标同图**（见 §5）。

### 4.2 报告核对

- 抽取时用目录的参考范围**校验**：报告自带范围与目录范围不一致时，两条都显示，不合并。
- 别名归一：`CA199` 识别为 `CA19-9`。

### 4.3 看板与并发症

| 触发 | 联动 |
|---|---|
| HGB 落入 70–99 | 看板「并发症」列出「消化道出血」为可能关联，链接到该指标 |
| PLT <50 | 看板「并发症」提示出血风险 |
| NEU <0.5 | 看板「毒性」提示粒缺，建议联系医生 |
| 总胆红素 + ALP 同时升高 | 看板「并发症」关联「胆道梗阻」 |
| 肌酐 / eGFR 异常 | 看板「治疗情况」提示可能影响化疗剂量 |

**所有联动只提示关联，不下诊断**。

## 5. 多指标趋势图的设计约束

用户要求「多个类型的多个指标」，而不是单个 CA19-9。这带来一个真实的技术约束：

**不同指标的单位与数量级差异极大**：

| 指标 | 单位 | 典型值 |
|---|---|---|
| CA19-9 | U/mL | 0–1000+ |
| HGB | g/L | 70–150 |
| 总胆红素 | mg/dL | 0.3–3 |
| CRP | mg/L | 0–100 |

**把它们画在同一条 y 轴上没有意义**（HGB 150 会把总胆红素 0.3 压成一条平线）。

### 5.1 三种可选呈现

| 方案 | 说明 | 评价 |
|---|---|---|
| **归一化折线**（推荐） | 每个指标按**自身参考范围**归一，画成「相对正常区间的偏离程度」 | 可同图比较趋势；y 轴无绝对值 |
| 小倍数图（small multiples） | 每个指标一个小图，纵向排列，**共享时间轴** | 保留绝对值，最准确；占空间 |
| 分组独立图 | 同单位的指标一组一张图 | 折中；但类别内单位仍可能不同 |

**推荐：默认「小倍数图」**，理由：

1. **保留原始数值**。医疗场景不能为了好看而丢掉绝对值。
2. **共享时间轴**让用户自己看出时间关联（同一时间点多个指标同时变化）。
3. 归一化会引入"参考范围是否可靠"的二次假设，而参考范围本身可能因检测机构不同而异。

**进阶**：提供「归一化叠加」开关，让想横向比较的用户切换。但**默认不归一化**。

### 5.1.1 配色规则（实测得出）

**每个指标一个唯一颜色**，且必须满足可区分性。规则：

| 规则 | 说明 |
|---|---|
| **唯一性** | 颜色按「当前可见的指标」动态分配，同屏绝不重复 |
| **同屏上限 8 个** | 实测：8 色是「两两可区分」的上限。超过后颜色必然相似，因此同屏最多显示 8 个指标，超出显示提示让用户缩小范围 |
| **明度分层** | 8 色的明度从 56 拉到 139（5 档），**灰度打印也能区分**，不只靠色相 |
| **红绿不参与** | 红绿留给状态语义（良好/关注/警示），不用于区分指标，避免语义冲突 |
| **脚本验证** | 任意两色的 RGB 距离 ≥80 或明度差 ≥26，由脚本断言保证 |

**为什么定 8 个上限**：我实际跑了穷举验证——10 色、20 色都无法在「低饱和医学界面可接受」的范围内做到两两可区分。这是感知限制，不是调色技巧问题。与其给相似的颜色，不如限制数量并明确告知。

8 色板：

| 色值 | 名称 |
|---|---|
| `#123E6B` | 深蓝 |
| `#8C3A1E` | 深赭 |
| `#1F7A6B` | 中青绿 |
| `#B58A16` | 中金 |
| `#5B2E80` | 深紫 |
| `#2E9CC4` | 亮蓝 |
| `#4A6B2A` | 橄榄 |
| `#C4648C` | 亮玫 |

### 5.1.2 图表风格

采用 **ECharts 折线图风格**：

| 元素 | 做法 |
|---|---|
| 曲线 | 平滑（Catmull-Rom 转三次贝塞尔），非折线 |
| 面积 | 线性渐变填充（同色 18% → 0%） |
| 数据点 | 白底圆环标记，每个点都有 |
| 末端数值 | 贴在图形右侧**独立留白区** |
| 参考范围 | 浅绿底带 |
| 警戒线 | 虚线，颜色随指标 |

### 5.1.3 标注防重叠

实测发现的问题：警戒线标签压在数据线上、末端数值与日期轴重叠。

修复规则：

| 标注 | 位置 |
|---|---|
| 警戒线标签 | **贴左侧内缘**（`x = 左边距 + 4`），纵向偏移 -4px 避开数据线 |
| 末端数值 | **右侧独立留白区**（`x = 图宽 + 7`），右侧留白 62px 专供它 |
| 日期轴标签 | 最多 4 个（首、1/3、2/3、末），首尾用 `text-anchor: start/end` 防溢出 |

断言：**同图内任意两个 `<text>` 的包围盒不得相交**，由脚本验证。

### 5.2 交互

| 元素 | 规则 |
|---|---|
| 类别筛选 | 六类（肿瘤标志物/血常规/肝功能/肾功能/感染/代谢）多选 |
| 指标选择 | 类别内多选，展开折叠参考现有组件 |
| 时间范围 | 沿用一图秀的年月筛选 |
| 参考范围带 | 每张小图画出参考区间底色带 |
| 危险线 | 有 `warnLow`/`dangerLow` 的指标**画出警戒线** |
| 数据表 | 每张小图下方可展开对应数据表 |

## 6. 指标卡片（值 + 状态 + 解读）

用户提供的示例格式（值/参考范围/状态/解读）应作为**指标详情卡**的模板：

```text
┌─ 血红蛋白 ─────────────────────────────┐
│ 110.0 g/L                              │
│ ↓ 低于参考范围 115–150                  │
│ 状态：偏低 🟡（关注）                   │
│                                        │
│ 解读：血红蛋白低于参考范围，进一步支持   │
│ 存在轻度贫血。其降低可能与营养不足、慢性 │
│ 疾病或骨髓造血功能有关，需结合病史分析。 │
│                                        │
│ 警惕：对胰腺癌患者，HGB 持续下降需注意   │
│ 消化道出血可能。                        │
└────────────────────────────────────────┘
```

**解读文字的三个约束**（重要）：

1. **描述数值事实**，不下诊断。可以写「提示可能存在轻度贫血」，不能写「你贫血了」。
2. **列可能原因**，不给结论。「可能与…有关」而非「就是因为…」。
3. **危险值单独提示**（如 HGB 的消化道出血关联），措辞为「需注意…可能」，且指向就医。

**解读内容来源**：随包资源里为每项指标预写模板，**不调用 AI 现场生成**。理由：解读涉及医学表述，需要审核；AI 现场生成无法保证一致与可控。

## 7. 参考范围的可靠性问题

必须处理的一个现实：

| 情况 | 处理 |
|---|---|
| 报告自带参考范围 | **优先用报告的**，因为不同机构、不同方法范围不同 |
| 报告无范围 | 用目录的通行范围，并标注「参考范围来自通用标准」 |
| 两者不一致 | **两条都显示**，不合并、不自动选一个 |
| 单位不同 | 不换算；分别显示并标注 |

**目录范围是兜底，不是权威**。这一点要在界面上说清楚。
