# 小胰宝弹窗动效提示词

来源：2026-10-14 的设计输入。此文件保留原始动效方向，供后续原型、设计稿和组件实现引用。

## 1. 毛玻璃浮层（Frosted Glass Sheet）

打开时背景页 backdrop-filter 模糊从 0 过渡到 26px，面板底色 rgba(255,255,255,0.42)，缩放从 0.94 到 1 浮起；12 个月格子按已用比例从底部填充，每格错开 4 帧，用 cubic-bezier(0.2,0.7,0.2,1) 在 1 秒内完成。

## 2. 圆环计数弹出（Ring Count Sheet）

底部面板用 cubic-bezier(0.2,0.7,0.2,1) 在 0.5 秒从屏幕外升到位，背景压暗到 40%；落定后圆环 stroke-dashoffset 用同一条曲线 1.2 秒画到剩余比例，中心数字从 0 同步滚到目标值。

## 3. 刻度尺进度弹出（Tick Ruler Sheet）

面板从下方滑入后，53 根周刻度从左到右逐根变深，每根错开 1 帧，到今天这一格换成强调色并停住；点击显示按钮，被遮的编号原地逐字展开，行高不变。

## 4. 照片抽屉弹出（Photo Drawer Sheet）

上半部照片按原比例从 1.08 缩小回 1 铺满，暗角托住白色大字；抽屉用 margin-top:-22px 压住照片底边，从下方推入，进度条随后从 0 涨到剩余比例。

## 在小胰宝中的使用约定

- 周期计划使用圆环表达“距离下次计划事项的时间进度”，不用于表达病情严重程度、疗效或风险等级。
- 化疗、血液检查、肿瘤标志物和增强 CT 可以共用圆环计数形式；中心显示周期或次数，旁边显示下次计划日期和剩余天数。
- 弹窗用于查看计划详情、修改提醒或查看历史。打开与关闭应保持短、可预期，并遵循系统的“减少动态效果”设置。
- 提醒卡和弹窗都要标明计划日期来自何处，并提示实际安排以医疗团队的医嘱、预约和检查单为准。
