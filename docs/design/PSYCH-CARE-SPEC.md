# 小胰宝工作台 · 心理支持规格

日期：2026-10-13 · 状态：**设计建议稿；外部资源信息经检索核实，但服务内容与联系方式需在使用前复核**。

上级文档：[SPEC-v0.4.md](./SPEC-v0.4.md)。本文定义**心理支持**一级 Tab 的四个二级页面。

---

## 1. 边界声明（最重要的一节）

心理支持模块涉及情绪、临终与哀伤，是本工作台**最敏感**的部分。先划清边界，再谈设计。

### 1.1 这个模块不做什么

| 不做 | 原因 |
|---|---|
| 心理诊断 | 工作台没有诊断资格 |
| 危机干预承诺 | 出现自伤/自杀风险时，工作台不能替代专业干预 |
| 自行解读量表分数 | 量表分界由各自官方标准定义，工作台只呈现，不解释 |
| 保证服务质量的外部资源 | 第三方机构的服务水平不由工作台背书 |
| 替代医生或心理咨询师 | 一切资源是「供你了解」，不是「建议你去做」 |

### 1.2 必须常驻的危机提示

**每一个心理支持页面底部固定显示**：

```text
如果你或家人出现伤害自己的想法，请立即联系：
· 全国统一心理援助热线 12356（24 小时）
· 希望24热线 400-161-9995
· 紧急情况请拨打 120

工作台不能提供危机干预，以上为公共服务信息。
```

这条**不可省略、不可折叠、不可只在某个子页显示**。原因：用户可能在任意一个心理相关页面进入情绪低谷，提示必须在场。

### 1.3 文案基调

面向正在经历重病与照护压力的真实的人。规则：

| 禁止 | 原因 |
|---|---|
| 「加油」「坚强」「一定能战胜」 | 施加情绪压力，否定真实感受 |
| 「保持乐观」「想开点」 | 无效安慰，隐含责备 |
| 「你已经很幸运了」 | 比较性否定 |
| 感叹号堆叠 | 制造紧迫感 |
| 打卡、连续记录、成就徽章 | 把情绪管理游戏化，不适合重病场景 |
| 「评估结果显示你……」 | 工作台不能下判断 |

使用平实、陈述性语言。允许表达「这很难」，不强行正向。

## 2. 信息架构

心理支持（一级 Tab）下四个二级页：

```text
心理支持
├─ 情绪自评        肿瘤患者常用量表，记录与趋势
├─ 心理缓解        社区「小馨宝」介绍、入群方式、自助方法
├─ 安宁疗护        医院与服务点查询、生前预嘱科普
└─ 哀伤管理        哀伤支持公益机构信息、哀伤常识
```

**设计意图**：这四页按「时间线」排列——从确诊后的情绪波动（自评）、到日常应对（缓解）、到疾病终末期的选择（安宁疗护）、到失去之后的哀伤（哀伤管理）。不是并列功能，是一条完整的照护路径。

## 3. 情绪自评

### 3.1 量表选择

肿瘤患者常用且中文版验证充分的工具：

| 量表 | 测什么 | 题数 | 分界（官方标准） | 用途 |
|---|---|---|---|---|
| **GAD-7** | 广泛性焦虑 | 7 | 5 / 10 / 15（轻/中/重） | 焦虑筛查，最常用 |
| **PHQ-9** | 抑郁 | 9 | 5 / 10 / 15 / 20（轻/中/中重/重） | 抑郁筛查，最常用 |
| **HADS** | 焦虑+抑郁 | 14 | 各 8 / 11（可疑/确定） | **专为躯体疾病患者设计，不含躯体症状条目** |
| **DT（痛苦温度计）** | 整体痛苦 | 1+问题列表 | ≥4 需关注 | NCCN 推荐，最简 |
| **SCL-90** | 综合 | 90 | 各因子 | 过长，不推荐常规使用 |

**推荐实现顺序**：DT（1 题，最快） → GAD-7 + PHQ-9（标准组合） → HADS（躯体症状干扰明显的患者）。

**关键点**：PHQ-9 含躯体症状条目（睡眠、食欲、疲劳），肿瘤患者因疾病本身就会高分，容易假阳性。因此界面必须提示：「PHQ-9 的部分条目与疾病症状重叠，得分偏高不一定代表抑郁，请结合 HADS 或与专业人员讨论。」这是**肿瘤心理评估的公认注意事项**，不能省略。

### 3.2 界面设计

```text
┌─ 情绪自评 ──────────────────────────────────┐
│ 最近一次：2026-10-01 · GAD-7 得分 12（中度）   │
│ 建议：可与专业人员讨论                        │
├──────────────────────────────────────────────┤
│ 量表选择  [DT 快速] [GAD-7] [PHQ-9] [HADS]   │
│                                              │
│ 得分趋势                                      │
│   GAD-7  ─────────────╮                      │
│         7 → 9 → 12    │  参考分界 5/10/15     │
│                       ╰─ 中度区间            │
│                                              │
│ 数据表：日期 · 量表 · 得分 · 分级 · 来源       │
└──────────────────────────────────────────────┘
```

规则：

- **分级用官方分界**，工作台不改写、不合并档位。
- 得分超分界时显示「可与专业人员讨论」，**不显示**「你有中度焦虑」。
- 趋势图沿用 v0.3 §7.1 规则：不插值、不合并不同量表（GAD-7 和 PHQ-9 分数不可比，不画同一条线）。
- 每次自评记录日期与量表版本，可导出给医生/咨询师。

### 3.3 自评触发时机

**不做推送、不做提醒、不做打卡**。只在用户主动进入时可用。理由：情绪自评被系统催着做，会变成压力源。

可选：在「全程管理」或看板心理维度显示「上次自评是 X 天前」，作为**中性事实**，不催促。

## 4. 心理缓解

### 4.1 社区「小馨宝」介绍

小馨宝是面向肿瘤患者及家属的 **AI 心理支持公益服务**（与「小胰宝」同属小 X 宝系列）。本页提供介绍与入群方式。

**用户协议已核实存在**：小馨宝 AI 心理支持服务用户协议（飞书文档）。

页面结构：

```text
┌─ 心理缓解 ──────────────────────────────────┐
│ 小馨宝 · AI 心理支持                          │
│ 面向肿瘤患者与家属的公益心理支持服务。          │
│ 提供 AI 陪伴对话与病友社群。                   │
│ [了解小馨宝]  [入群方式]                       │
├──────────────────────────────────────────────┤
│ 入群方式                                      │
│ · 微信公众号「小胰宝助手」                    │
│ · 社群入口（由管理员审核）                     │
│ · 使用前请阅读《小馨宝 AI 心理支持服务用户协议》│
├──────────────────────────────────────────────┤
│ 自助缓解方法（科普，非治疗建议）               │
│ · 呼吸练习 · 正念 · 书写 · 与家人沟通          │
└──────────────────────────────────────────────┘
```

**必须说明**：

- 小馨宝是**独立服务**，由社区运营，工作台只做介绍与入口，不代管其账号与数据。
- 使用前需阅读并同意其用户协议（工作台提供链接，不代同意）。
- 明确标注「AI 支持不能替代专业心理治疗」。

### 4.2 资源信息维护

外部资源（机构名、联系方式、入口）**会变化**，因此：

| 规则 | 说明 |
|---|---|
| 每条资源带核实日期 | 显示「信息核实于 2026-10-13」 |
| 过期提示 | 超过 6 个月未复核，标「可能已变更，建议自行确认」 |
| 数据来源标注 | 注明信息来源（官方公众号 / 官网） |
| 不承诺可用性 | 措辞用「可供了解」，不用「推荐」「保证」 |

**这是本模块所有外部资源页面共用的规则**（心理缓解、安宁疗护、哀伤管理）。

## 5. 安宁疗护

### 5.1 定位

面向疾病进展阶段的家庭，提供**信息**：什么是安宁疗护、哪里能做、如何选择、生前预嘱是什么。

**这不是「放弃治疗」的同义词**，界面必须澄清这一点（这是公众最常见的误解，也是患者抗拒安宁疗护的主因）。

### 5.2 页面结构

```text
┌─ 安宁疗护 ──────────────────────────────────┐
│ 安宁疗护（缓和医疗）旨在减轻痛苦、改善生活质量，│
│ 可与抗肿瘤治疗同时进行。                      │
├──────────────────────────────────────────────┤
│ 医院与服务点查询                              │
│ 地区 [选择]  机构类型 [全部 ▾]   [查询]        │
│ · 机构名 · 科室 · 联系方式 · 地址 · 床位       │
├──────────────────────────────────────────────┤
│ 生前预嘱                                      │
│ 什么是生前预嘱 · 如何订立 · 相关机构            │
├──────────────────────────────────────────────┤
│ 常见问题                                      │
│ · 安宁疗护是不是放弃治疗？                     │
│ · 在家还是住院？                              │
│ · 费用与医保                                  │
└──────────────────────────────────────────────┘
```

### 5.3 机构数据来源

已核实的公开参考资料：

| 来源 | 说明 |
|---|---|
| 北京生前预嘱推广协会 | 国内生前预嘱与缓和医疗的主要推动机构，发布《缓和医疗通讯录》 |
| 深圳市生前预嘱推广协会 | 同上，深圳地区 |
| 全球缓和医疗地图（The Global Palliative Care Map）| 国际对照，第 4 版覆盖 201 个国家和地区 |

《缓和医疗通讯录》收录了国内开展缓和医疗的医院与科室（含联系方式和地址），可作为机构库的初始数据来源。

**实现要求**：

- 机构库**随包离线可用**（安宁疗护场景常发生在网络不便的环境）。
- 每条机构信息带核实日期与来源。
- 提供「信息有误/已变更」的反馈入口。
- **不按「好坏」排序**，按地区或机构名排序。

### 5.4 敏感措辞

| 禁止 | 使用 |
|---|---|
| 「临终关怀」（可能引起抗拒） | 「安宁疗护」，必要时括注 |
| 「没救了」「治不了了」 | 「以减轻痛苦、改善生活质量为目标」 |
| 「你应该考虑」 | 「可以了解」 |
| 引导性排序或标记 | 中性列表 |

## 6. 哀伤管理

### 6.1 定位与时机

面向**已经失去亲人**的家属。这是最容易被忽略、但需求真实存在的一环。

**进入方式要克制**：不主动推送、不在患者档案里自动显示。由用户自己点进来。因为一个还在治疗中的家庭看到「哀伤管理」入口可能造成困扰。

**处理方式**：二级 Tab 常驻但措辞中性；页面开头说明适用对象。

### 6.2 已核实的公益资源

| 机构 / 热线 | 说明 | 联系方式 |
|---|---|---|
| **全国统一心理援助热线 12356** | 2025 年启用的全国统一号码 | 12356 |
| **希望24热线（Hope Line）** | 非政府非营利心理支持热线，全国 | 400-161-9995 |
| **春风网 / 春风热线** | 心理创伤援助公益平台 | 4006-333-858 |
| **Lifeline China** | 免费保密支持（英语） | 400 821 1215 |

| **星星港** | 失独家庭互助组织 | 见官方渠道 |

### 6.4 哀伤常识要点

内容需谨慎，只写公认的、非诊断性的信息：

- 哀伤是个体化过程，没有标准时长。
- 常见反应：悲伤、愤怒、麻木、内疚、sleep 与食欲变化（**记录症状是正常化，不是诊断**）。
- 什么情况建议寻求专业帮助：持续无法functioning、出现自伤想法、长期强烈痛苦无缓解。
- **不提供「哀伤阶段论」的强框架**（五阶段模型已被证明不是普适线性过程，用它会让「没走完阶段」的人产生额外压力）。

## 7. 数据与隐私

心理数据是**最敏感的个人数据**，规则比病历更严：

| 规则 | 说明 |
|---|---|
| 全部留在本机 | 与病历同一存储，不上传 |
| **不进入 AI 上下文** | 心理自评得分、哀伤页浏览记录**不发送给任何模型** |
| 不进看板需关注项 | 情绪分数不做红绿灯分级（见 §8） |
| 导出需显式确认 | 导出给医生/咨询师时列出具体内容 |
| 独立删除 | 可单独删除心理记录，不影响病历 |

**为什么心理数据不发给模型**：情绪状态与临终、哀伤相关的表达极度私密，一旦发送无法撤回。即使用户主动要求 AI 解读，也应提示「建议与专业人员讨论」而非让模型分析。

## 8. 与看板的关系（一处刻意的不一致）

看板有「心理」维度，但**心理维度不用红绿灯分级**。

理由：

1. 把情绪状态标成红色「警示」，会制造二次伤害。一个已经抑郁的人看到自己是红灯，只会更糟。
2. 情绪没有「客观异常值」这回事，与胆红素不一样。

**看板心理维度的呈现改为**：

| 有数据 | 无数据 |
|---|---|
| 「最近一次自评 2026-10-01」+ 中性色（不绿不红） | 「未评估」+ 补录入口 |

这是全看板唯一不用红绿灯的维度，**必须在实现时明确标注例外**，否则容易被误改为红绿灯。
