# 小胰宝工作台 · 基因与病理靶点面板规格

日期：2026-10-13 · 状态：**设计建议稿；靶点清单基于 NCCN 2025.V1 与已收到的真实模版，待用户确认**。

上级文档：[SPEC-v0.4.md](./SPEC-v0.4.md) · [CASE-TEMPLATE-SPEC.md](./CASE-TEMPLATE-SPEC.md)。

---

## 1. 核心设计原则：基因与病理是两件事

用户明确要求：「**基因检测和病理不一样**」。这个区分必须落到数据模型和界面上。

| | 基因检测（Molecular） | 病理 / IHC（Protein） |
|---|---|---|
| 检测对象 | DNA / RNA | 蛋白表达 |
| 方法 | NGS panel、PCR、FISH | 免疫组化（IHC） |
| 结果形态 | 变异（突变/融合/扩增/缺失）+ 丰度 | 表达强度（阳性/阴性/百分比/评分） |
| 典型结果 | KRAS G12D，丰度 24.86% | CLDN18.2 阳性 20%（弱-中等） |
| 能否定量 | 可（VAF、TMB） | 半定量（百分比 + 强度） |
| 与治疗关系 | 直接对应靶向药（如 KRAS G12D 抑制剂） | 对应 ADC / 单抗（如 CLDN18.2 ADC） |
| **界面呈现** | **卡片 + 浅绿（有）/ 浅灰（无）** | **卡片 + 背景色表示阳性强度** |

**结论**：不合并成一张表。两个独立分组，各自的卡片语言不同。

## 2. 基因检测面板

### 2.1 覆盖的基因与分型

用户列出的：KRAS 分型（12D/12V/12R/Q61H 等）、TP53、BRCA1/2、CDKN2A、ERBB2、ERBB3、V600E、ATM、VEGF、SMAD4。

经 NCCN 2025.V1 与文献补充后，推荐的完整清单：

#### A. 胰腺癌高频驱动基因（几乎必查）

| 基因 | 常见变异 | 胰腺癌中的意义 |
|---|---|---|
| **KRAS** | G12D / G12V / G12R / G12C / G12S / G12A / Q61H / Q61R / Q61K / G13D | 约 90% PDAC 有 KRAS 突变。**分型直接决定可用抑制剂**（G12D 与 G12C 药物不同） |
| **TP53** | 多位点突变 | 最常见共突变，影响预后 |
| **CDKN2A** | 缺失 / 突变 | 细胞周期调控，PDAC 四大驱动之一 |
| **SMAD4** | 缺失 / 突变 | 与转移倾向和预后相关 |
| **ARID1A** | 截断突变 | 染色质重塑，真实模版中出现 |

#### B. 可操作靶点（NCCN 明确推荐检测）

| 基因 | 变异类型 | NCCN 2025.V1 相关 |
|---|---|---|
| **BRCA1 / BRCA2** | 致病突变 | 胚系/体系，铂类与 PARP 抑制剂 |
| **PALB2** | 致病突变 | 同 BRCA 通路 |
| **HER2 (ERBB2)** | 扩增 / 过表达 | IHC3+ 或 IHC2+ 且 FISH 扩增 → 德曲妥珠单抗 |
| **BRAF V600E** | 点突变 | 可操作 |
| **NTRK1/2/3** | 融合 | 恩曲替尼、拉罗替尼（NCCN 新增） |
| **NRG1** | 融合 | 可操作 |
| **ALK / ROS1 / RET / FGFR2** | 融合 | NCCN 推荐检测融合 |
| **FGFR** | 基因改变 | Erdafitinib（NCCN 新增） |
| **MSI / dMMR** | 状态 | MSI-H/dMMR → 帕博利珠单抗、多塔利单抗 |
| **TMB** | 数值 | TMB-H ≥10 mut/Mb → 免疫治疗 |
| **ATM** | 突变 | DNA 修复，铂类敏感性 |
| **ERBB3** | 突变 | 用户指定，HER 家族 |
| **VEGF** | 表达/多态性 | 用户指定，抗血管生成相关 |
| **胚系（germline）** | BRCA1/2、PALB2、ATM 等 | 与遗传风险、家系筛查相关 |

#### C. 关于用户清单的说明

| 用户列出 | 处理 |
|---|---|
| KRAS 12D/12V/12R/Q61H | ✅ 已展开为完整分型清单（含 G12C，因有对应药物） |
| TP53、BRCA1/2、CDKN2A、ERBB2、ERBB3、V600E、ATM、VEGF、SMAD4 | ✅ 全部纳入 |
| **V600E** | ⚠️ 澄清：V600E 是 **BRAF 基因的变异位点**，不是独立基因。界面应显示为「BRAF V600E」，避免建模为独立靶点 |
| 补充 | ARID1A、PALB2、NTRK、NRG1、ALK/ROS1/RET/FGFR2、MSI、TMB |

### 2.2 基因卡片设计

**每个基因一张卡片，状态用背景色区分（用户要求：浅灰=无，浅绿=有）**：

```text
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ KRAS            │  │ TP53            │  │ BRCA1/2         │
│ G12D            │  │ 突变            │  │ 未检出致病突变    │
│ 丰度 24.86%     │  │ c.818G>A        │  │                 │
│ 浅绿底 · 有变异   │  │ 浅绿底 · 有变异   │  │ 浅灰底 · 无      │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

卡片状态语义：

| 状态 | 背景 | 文字 | 含义 |
|---|---|---|---|
| `positive` 有变异 | 浅绿 `#E4F1EA` | 绿 `#1F6B4F` | 检出该变异 |
| `negative` 无变异 | 浅灰 `#F1F3F2` | 灰 `#6B7B73` | **做过检测**，未检出 |
| `untested` 未检测 | 白底 + 虚线边框 | 灰 | **没做过**，与「无变异」严格区分 |
| `vus` 意义未明 | 浅黄 `#FFF3D4` | 金 `#805C17` | 检出变异但临床意义未明 |

**`negative` 与 `untested` 必须视觉可分**。这是整套设计里最容易出错、后果最严重的一点：「没检测」被显示成「阴性」，会让用户以为这条路已经排除。

### 2.3 KRAS 分型的特殊处理

KRAS 是唯一需要「基因 + 分型」两级的：

```text
┌──────────────────────────────┐
│ KRAS            浅绿 · 有变异  │
│ G12D                         │
│ 丰度 24.86% · NGS 组织        │
│ 2026-08-02                   │
│ 可关注：KRAS G12D 抑制剂类试验  │
└──────────────────────────────┘
```

**「可关注」不是推荐治疗**，只说明该类试验通常要求该变异。措辞受 [MATCHING-SPEC §1.2](./MATCHING-SPEC.md) 约束。

### 2.4 数据来源：从报告提取 + 手动补充

用户要求：「基因检测结果是从报告中提取，更新到这里，可以根据文档提取内容增加才对」。

流程：

```text
上传基因检测报告（PDF/图片）
  → 文本提取
  → 识别基因名 + 变异 + 丰度 + 方法 + 日期
  → 生成候选卡片（虚线边框，标「待核对」）
  → 用户核对确认
  → 实心卡片进入正式面板
```

关键规则：

- **未在面板清单中的基因也能进**。清单是「常见项默认展示 + 未测项占位」，不是白名单。报告里出现新基因（如 STK11、KEAP1）时自动追加卡片，不丢弃。
- 真实模版中已出现 STK11 p.L50*，属于补充项，必须支持。
- 抽取候选**不自动确认**，沿用 v0.3 主链规则。

### 3.2 病理卡片设计

**用卡片 + 背景色表示阳性（用户要求）**。阳性强度分档：

| 结果 | 背景 | 边框色 | 文字 |
|---|---|---|---|
| 强阳性（3+ / >50%） | 深绿 `#C9E6D5` | `#4E9670` | 深绿 |
| 阳性（2+ / 20-50%） | 中绿 `#DCEFE3` | `#6DAF88` | 绿 |
| 弱阳性（1+ / <20%） | 浅绿 `#EDF6F0` | `#94C4A8` | 绿 |
| 阴性 | 浅灰 `#F1F3F2` | 无 | 灰 |
| 未检测 | 白底 | 虚线 | 灰 |
| 不确定 / 部分+ | 浅黄 `#FFF8E6` | `#E0C176` | 金 |

```text
┌────────────────┐ ┌────────────────┐ ┌────────────────┐
│ CLDN18.2       │ │ B7-H3          │ │ HER2           │
│ 阳性 · 20%     │ │ 阳性 · 2+ · 60%│ │ 0              │
│ 弱-中等强度     │ │                │ │                │
│ 中绿底          │ │ 深绿底          │ │ 浅灰底 · 阴性   │
└────────────────┘ └────────────────┘ └────────────────┘
```

**注意 `HER2(0)` 是阴性不是未检测**，用浅灰实底；而完全没做过的用虚线白底。

### 3.3 SLN 的歧义（必须确认）

「SLN」在肿瘤语境下有多个含义，**不能猜**：

| 可能含义 | 领域 | 是否合理 |
|---|---|---|
| **SLN = 前哨淋巴结**（Sentinel Lymph Node） | 手术病理 | 胰腺癌通常不做前哨淋巴结活检（与乳腺癌/黑色素瘤不同），作为**IHC 靶点**说不通 |
| **SLN = 慢病毒/载体相关** | 基因治疗 | 不太可能 |
| **SLN = 某个标志物缩写** | 待确认 | 需要用户澄清确切全称 |

**处理**：在规格中标为「待确认」，界面上不预设该卡片；用户澄清后再加入。**不猜、不塞一个可能错误的含义进去**——这是医疗数据，错一个缩写会误导判断。

## 4. 与临床匹配的复用（用户强调「非常关键」）

基因/病理面板**不是独立展示页**，它是匹配分析的核心输入。复用规则：

### 4.1 单一事实来源

```text
基因/病理卡片（本面板，可手动补录 + 报告提取）
        ↓ 同一份数据，不做副本
入组档案 · 分子特征分组
        ↓
TrialEligibilityRule 求值（genomic_marker / msi_status / her2_status 等）
        ↓
匹配三档结果
```

**不允许**在匹配模块里再维护一份「匹配专用基因表」——这与 SPEC-v0.4 §4.2 对治疗线数的要求一致。

### 4.2 字段映射到规则

| 卡片状态 | 匹配规则取值 | 判定 |
|---|---|---|
| `positive` 有变异 | 字段存在且符合条件 | **已满足**（如试验要求 KRAS G12D） |
| `positive` 但变异不符 | 字段存在但值不同 | **可能冲突**（如试验要 G12C，患者是 G12D） |
| `negative` 无变异 | 字段存在，值=阴性 | 视规则而定。若试验要求阳性 → **可能冲突** |
| `untested` 未检测 | 字段缺失 | **无法判定**（绝不判「已满足」） |
| `vus` 意义未明 | 字段存在但不确定 | **无法判定** |

这张表是整个匹配系统安全性的关键。`untested → 无法判定` 这条不变量与 [MATCHING-SPEC §4.2](./MATCHING-SPEC.md) 完全一致。

### 4.3 KRAS 分型对匹配的特殊价值

胰腺癌试验高度按 KRAS 分型分层（G12D/G12V/G12C 各有专属试验）。因此：

- KRAS 卡片必须记录**具体分型**，只记「KRAS 突变」不足以匹配。
- 若报告只写「KRAS 突变」未写分型 → 卡片标「**分型未记录**」，KRAS 相关规则判「无法判定」，并提示「可查看原始报告确认分型」。

### 4.4 面板完整度影响

看板「可匹配临床」维度依赖面板完整度。面板缺项时：

- 缺关键位点（KRAS 分型、MSI、HER2、CLDN18.2）→ 看板提示「分子特征不完整，部分试验无法判定」。
- 提供「补充检测建议」入口，但**不推荐具体检测项目作为医疗建议**，只列出「与当前收藏试验相关的缺失项」。

## 5. 界面布局

### 5.1 位置

基因/病理面板放在**临床匹配 · 入组档案**页，分为两个独立分组卡片：

```text
入组档案
├─ 基因检测（分子特征）        ← 本规格 §2
│  └─ 卡片网格：有变异=浅绿，无=浅灰，未检测=虚线
├─ 病理 / 免疫组化（IHC）       ← 本规格 §3
│  └─ 卡片网格：阳性强度=背景深浅
├─ 并发症状态
├─ 治疗线数与方案
└─ 基本与体能
```

同时在**病情整理 · 病情评估**页显示只读摘要，链接回入组档案编辑（避免两处编辑冲突）。

### 5.2 布局规则

**默认只展示阳性/有变异，未检测与未突变折进可展开区。**

理由：一次 NGS panel 常有几十个基因，其中大部分是「未检出」。如果全部平铺，真正有意义的那几个阳性项会被淹没在灰色卡片海里。折叠后首屏只剩需要关注的信息。

```text
有变异 4 项
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│ KRAS │ │ TP53 │ │ARID1A│ │STK11 │
└──────┘ └──────┘ └──────┘ └──────┘

▸ 展开未突变 / 未检测       6 项未突变 · 4 项未检测
```

展开后显示浅灰（未突变）与虚线白底（未检测）两类卡片，并附说明区分二者。

**折叠计数必须同时给出两个数字**（未突变 N 项 / 未检测 N 项），因为它们含义不同。

### 5.3 基因科普（点击基因名）

每个基因名是一个可点击的链接（带 `i` 圆形标记）。点击弹出该基因的一句话科普。

| 项 | 规则 |
|---|---|
| 内容层级 | 通行教科书级描述：基因功能 + 在胰腺癌中的意义 |
| 长度 | 一句话到两句话，不超过 100 字 |
| **必须带免责** | 「以上为通行教科书级描述……不构成诊断或治疗建议，具体含义请以医生解释为准」 |
| **禁止** | 不写具体用药建议、不写预后判断、不写「你应该检测什么」 |
| 无词条时 | 基因名不可点击（不弹空框） |

**内容示例（KRAS）**：

> RAS 家族原癌基因。胰腺癌中约 90% 存在 KRAS 突变，是最常见的驱动基因。不同位点（G12D、G12V、G12C 等）对应的研究药物不同，因此报告会写明具体分型。

**为什么值得做**：患者拿到 NGS 报告时，最常见的困惑就是「这些基因名是什么意思」。一句话科普能显著降低理解门槛，且不越界——它解释名词，不给建议。

**词条覆盖**：基因 19 项 + 病理靶点 24 项，共 40 余条。未收录的基因名保持不可点击。

### 5.4 列数与排序

| 容器宽度 | 卡片列数 |
|---|---|
| W ≥ 1080 | 4 列 |
| 760 ≤ W < 1080 | 3 列 |
| 520 ≤ W < 760 | 2 列 |
| W < 520 | 2 列（卡片本身很小，不折单列） |

默认排序：**有变异/阳性在前**（展开区内则未突变在前、未检测在后）。理由：用户最关心「有什么」，其次关心「还差什么」。

### 5.5 与用户要求的配色对应

用户要求「红绿灯指标」。在基因/病理面板内：

- **浅绿 = 有（阳性）** ✅ 用户明确要求
- **浅灰 = 无（阴性）** ✅ 用户明确要求
- 未检测 = 虚线（补充定义，因为它不能等于「无」）

红黄绿三色主要用于**看板维度**（见 [DASHBOARD-SPEC](./DASHBOARD-SPEC.md) §1.2 的修订），面板内则用绿色深浅表达强度、灰色表达阴性。
