# 营养制剂本地参考资料

本目录保存用户提供的制剂对比和类型资料，用于工作台本机开发、检索和营养制剂使用记录。

| 文件 | 内容 |
| --- | --- |
| nutrition-formula-comparison.png | 多种营养制剂的产品参数对比表截图。 |
| enteral-nutrition-formula-types.png | 肠内营养制剂类型、通用名、特点和图表资料中列出的适用人群截图。 |
| nutrition-formula-reference.json | 对类型资料建立的本机检索索引。 |

工作台使用这些资料帮助整理“使用了什么、何时使用、用量和耐受情况”。产品选择、具体用量和是否适合个人情况以产品标签及医疗或营养专业人员意见为准。
