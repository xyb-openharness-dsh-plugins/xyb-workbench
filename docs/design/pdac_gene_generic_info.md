# 胰腺导管腺癌基因与病理参考信息

用途：为小胰宝工作台的“病情整理”和“临床匹配”提供通用字段、名词说明与展示规则。本文件不是个体报告解读、诊断或治疗建议。

## 1. 来源与边界

本稿从以下材料整理通用信息：

- `gene.pdf`：肿瘤基因检测报告的检测范围、体细胞与胚系变异分级、TMB、MSI、融合和报告局限性。
- `华梵安-一体机报告模板1-标准.docx`：肿瘤 NGS 报告应保留的字段，包括样本、检测方法、变异类型、丰度/拷贝数、转录本、证据等级、TMB、MSI 和胚系结果。
- `胰腺癌典型病理.md`：胰腺肿瘤免疫表达谱，尤其是导管腺癌与腺泡细胞癌、神经内分泌肿瘤、实性假乳头状肿瘤的鉴别线索。

材料中的个人信息和个案结果不进入本文件。本文列出的是 PDAC 中常被关注或需根据报告决定是否记录的项目；“典型”不表示每位患者都会检出，也不能从“未检出”推断检测范围以外的情况。

## 2. 工作台的记录规则

每个基因或病理项目应保存：项目名、结果原文、标准化结果、检测类型、样本类型、检测方法、报告日期、原报告页/证据定位、确认状态。

基因类结果必须区分：检出变异、检测阴性、未检测、检测失败/质量不足、临床意义未明。免疫组化结果必须保留评分、阳性细胞比例、判读标准和实验室原文；“表达保留”“阴性”“未检测”不可互换。

通用参考卡只用于提示“可以在报告中找什么”。只有用户核对并确认过的项目，才能显示为当前患者结果，或用于临床匹配条件对照。

## 3. PDAC 常见驱动基因

| 项目 | 为什么在工作台中保留 | 记录时应看什么 |
| --- | --- | --- |
| KRAS | PDAC 中最常见的驱动改变之一；不同具体位点不能混写。 | 氨基酸/核酸位点、变异类型、丰度、样本、方法；例如 G12、Q61 等需原样保留。 |
| TP53 | 常见肿瘤抑制基因改变。 | 具体变异、丰度、分类；IHC p53 表现只能作为相关信息，不能替代 NGS 结果。 |
| CDKN2A | PDAC 常见驱动通路相关项目。 | 突变、缺失或其他改变类型；报告未覆盖时标“未检测”。 |
| SMAD4 | PDAC 常见驱动通路相关项目；病理可出现 DPC4 蛋白表达信息。 | 基因结果与 DPC4 IHC 分开记录，并关联同一份报告或标本。 |

## 4. 需要按报告保留的扩展分子项目

| 组别 | 项目 | 工作台说明 |
| --- | --- | --- |
| 同源重组修复与遗传风险 | BRCA1、BRCA2、PALB2、ATM、CHEK2、RAD51 系列及报告实际覆盖的其他 HRR 基因 | 体细胞和胚系结果分开存；胚系结果应保留致病性分级和遗传咨询状态。 |
| 错配修复与免疫相关 | MLH1、MSH2、MSH6、PMS2、MSI、TMB、POLE、POLD1 | MSI、MMR IHC 和基因改变是不同检测层面；TMB 的数值、单位、算法/平台和实验室解释应一并保留。 |
| 融合与少见可操作改变 | NTRK1/2/3、NRG1、FGFR2/3、ALK、RET、ROS1 | 必须先记录检测是否覆盖融合；“未检测”不能写成阴性。 |
| 其他常见扩展项 | BRAF、ERBB2/HER2、PIK3CA、PTEN、RNF43、GNAS 等 | 是否纳入取决于实际面板和报告；工作台保留原始变异类型，如突变、扩增、融合或缺失。 |

## 5. PDAC 病理与免疫组化参考

病理.md 中导管腺癌一行给出的表达谱可作为“查找线索”，不能作为单个标志物的诊断规则。工作台应把诊断原文放在第一位，把 IHC 面板作为证据补充。

| 分组 | 常见于导管腺癌报告中可见的项目 | 展示和解释规则 |
| --- | --- | --- |
| 导管/上皮相关 | CK7、CK8、CK18、CK19、EMA、CEA、MUC1、MUC3、MUC5/MUC6、CA19-9、CA125、Claudin-4、S100P | 可按“阳性/阴性/比例/强度”存储；不要用单项自动判定原发部位。 |
| 辅助或鉴别相关 | PDX-1、Maspin、CK4、CK17、间皮素、CDX-2、肌成束蛋白、IMP3、HER2、E-cadherin | 展示实验室原文和判读，不在工作台中自动推出诊断结论。 |
| DPC4/SMAD4 与 p53 | DPC4（SMAD4）、P53 | 作为 IHC 项独立保存；可链接对应 NGS 项目，但两者不能相互替代。 |
| MMR 蛋白 | MLH1、MSH2、MSH6、PMS2 | “表达保留”记录为 IHC 结果；与 MSI 和 MMR 基因检查分层展示。 |
| 鉴别诊断提示 | CK20、MUC2、胰蛋白酶、脂肪酶、嗜铬粒蛋白、突触素、β-catenin、CD56 等 | 仅在病理医生已写入报告时记录，用于保留证据，不能由工作台自行勾选诊断。 |

## 6. 用户界面建议

默认只显示已确认且与当前查询相关的关键项目，例如 KRAS、TP53、CDKN2A、SMAD4、BRCA1/2/PALB2、MSI/MMR、TMB 和报告实际检出的融合或扩增。其余项目收进“完整面板”，按“已检出、检测阴性、未检测/未覆盖、意义未明”筛选。

每张卡片显示项目、患者结果或“尚未导入”、检测层面、来源日期和确认状态。通用定义放在“这是什么”中；与试验条件有关的内容必须跳转到逐项对照，不显示“推荐入组”。

## 7. 报告局限性提示

NGS 面板的覆盖范围、样本肿瘤细胞比例、测序深度、变异丰度、检测下限、方法和数据库版本都会影响结果。检测阴性不排除面板外或低于检测限的改变；不同时间、不同部位和不同方法的结果可能不同。工作台应保留报告原文与日期，并在跨报告对照时提示来源差异。
